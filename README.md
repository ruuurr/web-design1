# Серебрякова Александра 4-МД-15 портфолио

Персональный сайт-портфолио с информацией об авторе, образовании, навыках и проектах в области дизайна и веб-разработки.

## Технологии

- HTML5
- CSS3
- JavaScript

## Как запустить локально

1. Скачайте проект.
2. Убедитесь, что файлы `index.html`, `style.css` и `main.js` находятся в нужных местах.
3. Откройте `index.html` в браузере.

Установка дополнительных пакетов не требуется.

## Функции JavaScript

- Переключение тёмной и светлой темы с сохранением выбора.
- Фильтрация проектов по категориям.
- Открытие и закрытие мобильного меню.
- Закрытие меню при выборе раздела или нажатии `Escape`.
- Отображение заглушки при недоступности изображения проекта.

## Публикация на GitHub Pages

1. Зарегистрируйтесь на [GitHub](https://github.com/).
2. Создайте репозиторий с помощью кнопки **New repository**.
3. Загрузите файлы сайта: `index.html`, `style.css`, `main.js` и необходимые изображения.
4. Откройте репозиторий и перейдите в **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`.
7. Нажмите **Save**.
8. Дождитесь публикации и откройте ссылку, появившуюся в разделе **Pages**.

После загрузки новых изменений сайт обновится автоматически после завершения публикации.
